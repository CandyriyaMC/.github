# Support

Having trouble with a CandyriyaMC project? Here's where to go, fastest first.

| You have… | Go here |
| --- | --- |
| Someone online to talk to | [Discord](https://discord.gg/fXwN4wETF9) — the CandyriyaMC community server |
| A usage question ("how do I…") | [Discussions](https://github.com/CandyriyaMC/.github/discussions) → Q&A |
| An idea or a showcase | [Discussions](https://github.com/CandyriyaMC/.github/discussions) → Ideas / Show and tell |
| A bug | The affected repository's issue tracker (bug report template) |
| A feature request | The affected repository's issue tracker (feature request template) |
| A security vulnerability | [SECURITY.md](SECURITY.md) — private reporting only |

Each repository also keeps its own documentation in its `docs/` directory and its `README.md`. Check there first — it's usually faster than waiting for an answer.

Please note: this is a community-run organization. Support is best effort, and response times vary. Search existing issues and discussions before asking — your question may already be answered.
